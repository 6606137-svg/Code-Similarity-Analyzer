AI-Based Plagiarism Detection & Code Similarity Analyzer

Project Overview

This project analyzes source code and compares code submissions to identify similarities and potential plagiarism.

Features

- Code similarity analysis
- Backend API using Python and Flask
- Frontend interface using HTML, CSS, and JavaScript
- Similarity result display

Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

Project Structure

- "backend/": Backend application and similarity analysis
- "frontend/": Website interface
- "docs/": Project documentation

How to Run

1. Install the dependencies listed in "backend/requirements.txt".
2. Start the backend application.
3. Open the frontend using the configured local server.
4. Submit code samples to test similarity analysis.
